# Historical precedent and sensor integrity

Use this skill when a recurring process pattern, sensor reversal, connectivity gap,
or installation change could explain the alarm.

1. Compare the current pattern with a specific historical interval of similar depth
   and duration.
2. A precedent supports Healthy only when it clearly recovered to the normal baseline.
3. Suspect flipped labels only when reversal is long-standing or follows a clear
   instrumentation gap into a durable new regime.
4. A reversal that emerges gradually is abnormal behavior, not evidence that the
   labels were always flipped.
5. If the selected precedent is not genuinely comparable, choose another skill or
   classify with appropriately low confidence.

Use `compare_current_with_history` to obtain side-by-side chart evidence.
